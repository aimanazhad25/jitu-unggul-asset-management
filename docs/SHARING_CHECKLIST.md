# Before making this repository public

This source package has been prepared for sharing, but repository owners should still:

1. Obtain permission to publish source code developed for Jitu Unggul.
2. Ensure no sensitive business logic, private data, test accounts or customer details remain.
3. Check Firebase Authentication and Cloud Firestore security rules in the Firebase console.
4. Avoid committing original `android/key.properties`, generated browser profiles, and `backup/` contents.
5. Keep credentials and production Firebase deployment access private.

The original app hosted on Firebase is not modified by publishing this source package.
